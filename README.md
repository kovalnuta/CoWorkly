# CoWorkly — Система бронирования коворкинга

Настольное приложение на базе WPF для управления бронированием рабочих мест в коворкинге. Приложение предоставляет интерактивную карту трехэтажного здания с трехуровневой навигацией (этаж → комната → место) и реализует алгоритм проверки конфликтов бронирований.

## Функциональные возможности

- Интерактивная карта трехэтажного здания коворкинга.
- Трехуровневая навигация: выбор этажа, выбор комнаты, выбор конкретного места в сетке комнаты.
- Бронирование мест по клику с автоматической проверкой временных конфликтов.
- Цветовая индикация статусов мест:
  - свободно;
  - забронировано текущим пользователем;
  - занято другим пользователем.
- Разделение ролей: администратор и клиент.
- Хранение данных в локальной реляционной базе данных SQLite.

## Стек технологий

- **Язык программирования:** C# 12
- **Платформа:** .NET 8.0 (LTS)
- **Интерфейс:** WPF (Windows Presentation Foundation)
- **Архитектура:** MVVM с использованием CommunityToolkit.Mvvm
- **База данных:** SQLite через Entity Framework Core 8
- **Внедрение зависимостей:** Microsoft.Extensions.DependencyInjection
- **Система контроля версий:** Git, GitHub

## Системные требования

- ОС: Windows 10 или Windows 11 (x64)
- Установленная среда выполнения: .NET 8.0 Runtime
- Свободное место на диске: не менее 50 МБ

## Инструкция по запуску из чистого клона

### Шаг 1. Клонирование репозитория

```bash
git clone https://github.com/ВАШ_ЛОГИН/CoWorkly.git
cd CoWorkly
```

### Шаг 2. Восстановление зависимостей и сборка

```bash
dotnet restore
dotnet build
```

Либо откройте файл `CoWorkly.sln` в Visual Studio 2022 и выберите в меню **Сборка → Перестроить решение**.

### Шаг 3. Запуск приложения

```bash
dotnet run --project CoWorkly
```

Либо нажмите клавишу **F5** в Visual Studio.

### Шаг 4. Первичная настройка и проверка

1. В окне входа выберите пользователя (например, Администратор).
2. В главном окне нажмите кнопку **«Создать тестовые данные»** для инициализации структуры здания и рабочих мест.
3. Выберите этаж, затем комнату и кликните на свободное место для его бронирования.
4. Выйдите из системы, войдите под другим пользователем и попробуйте забронировать то же место, чтобы проверить срабатывание защиты от конфликтов.

## Структура проекта

- `CoWorkly.sln` — файл решения Visual Studio.
- `CoWorkly` — основной проект приложения.
  - `Models` — папка с моделями данных (`User`, `Floor`, `Room`, `Seat`, `Booking`).
  - `Data` — папка с контекстом базы данных (`AppDbContext`).
  - `ViewModels` — папка с моделями представления и бизнес-логикой.
  - `Views` — папка с XAML-разметкой пользовательского интерфейса.
- `CoWorkly.Tests` — проект с модульными тестами.
